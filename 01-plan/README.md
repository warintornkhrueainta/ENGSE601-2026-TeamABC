## ส่วนที่ใช้ต่อในครั้งที่ 3

คัดลอก **Entry และ Exit Criteria ของทีม** จากใบงานครั้งที่ 1 มาไว้ตรงนี้ด้วย เพื่อให้หาง่าย

| ประเภท | เกณฑ์ของทีม |
|---|---|
| Entry | มีข้อมูลรายชื่อเจ้าของสำหรับทดสอบ ทั้งทรัพยากรที่มีเจ้าของและที่ไม่มีเจ้าของ |
| Entry | C-03 และ C-04 ติดตั้งบนเครื่องทดสอบ และผ่าน Unit Test แล้ว |
| Exit | รันกรณีทดสอบครบทั้งกรณีส่งสำเร็จ และกรณีหาเจ้าของไม่พบ |
| Exit | ไม่มีข้อบกพร่องระดับสูงค้างอยู่ในการส่งรายการ |

## ทีมที่ยังไม่มีเอกสารออกแบบของโครงงาน

วาดภาพส่วนประกอบจากโค้ดหรือแผนที่มีจริง แล้วติดป้ายว่า “สร้างย้อนหลัง” หรือเขียนช่องว่างว่าขาดเอกสารใด ใครรับผิดชอบ จะได้เมื่อไร · ห้ามแต่งข้อค้นพบที่ไม่ได้ตรวจจริง
